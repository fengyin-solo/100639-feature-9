# 城市地下综合管廊运行维护管理平台

面向管廊主体台账、入廊管线登记、廊内环境监测、通风排水消防、结构沉降与渗漏处置、巡检检修与隐患整改、入廊作业审批和运维值班的一体化城市地下综合管廊运行维护管理工作台。

这是一个**纯前端**管理平台：Vue 3 + Vite + TypeScript，仓库里没有后端服务。业务数据由
`frontend/src/data/` 下的本地数据层提供：首次打开用示例数据播种，之后的登记、筛选与状态流转
结果都持久化在浏览器 `localStorage` 里，刷新或重开浏览器都还在。dev server 已关掉自动打开页面，
启动后按终端打印的地址手工打开。

## 目录结构

```text
.
├── frontend/                 Vue 3 + Vite + TypeScript 前端（唯一运行单元）
│   ├── src/views/            每个业务模块一个页面
│   ├── src/api/local-service.ts   本地数据服务：列表、筛选、动作流转、导出
│   ├── src/data/             模块元数据 / 示例数据 / localStorage 持久化
│   ├── src/stores/           会话与筛选状态
│   └── vite.config.ts        dev server 配置（open: false，无 /api 代理）
├── .gitignore
└── docker-compose.yml
```

## 启动

```bash
cd frontend
npm install
npm run dev
```

前端默认监听 `http://127.0.0.1:5173/`，dev server 不会自动打开浏览器，需要自己访问。

生产构建：

```bash
cd frontend
npm run build
```

## 约定

- 每个模块的页面在 `frontend/src/views/<模块>/index.vue`，页面只负责渲染，读写统一走
  `frontend/src/api/local-service.ts`。
- 字段、状态、动作与流转目标集中在 `frontend/src/data/modules.ts`；示例数据在
  `frontend/src/data/seed.ts`。
- 状态流转只允许在 `local-service.ts` 里改，页面组件不做业务判断。
- 想回到初始数据：清掉浏览器里 `urban-utility-tunnel:entries` 这一项，或调用 `resetModule(模块)`。

## 通风系统运维的异常情形约定

- **空值与 0 不许混为一谈**：`送风风速` 取不到时是空态（`null`），页面显示「暂无」并写明
  取数失败的原因；`0` 是有效测量值，照常显示 `0 m/s`。环境监测的四个指标列同理。
- **取数与重试**：送风风速模拟现场采集（`fetchAirSpeed`）。待开机 / 已停机 / 故障停机
  取不到数，原因分别是「机组未开机，无送风数据」「机组已停机，现场无送风数据」
  「机组故障停机，采集通道中断」；运行中的机组偶发「现场采集网关超时」，点「重新取数」
  会真正再取一次。列表整体读取失败时同样留空态、写原因、给重试。
- **停机原因**：登记停机、上报故障都必须填原因；故障停机的机组在清单里单独标红说明。
- **故障上报幂等**：同一机组重复上报故障只记一次，反复点不会重复置成故障停机，
  派工单也不会重复生成。
- **存量回填**：老数据读库时自动迁移（`frontend/src/data/migrations.ts`）——
  故障停机没登记原因的补「历史故障停机，原因未登记，按启停时间补录」，已停机的补
  「计划性停机（历史数据补录）」；缺启停时间的按该机组操作记录里最早一次动作推定。
- **通风 ↔ 环境监测联动**：已停机 / 故障停机的机组会在环境监测页顶部提示，对应舱室的
  监测行显示「本舱室通风已停」，该舱室监测数据取不到时空态说明里同步带上通风停机情况。
- **派工清单**：故障停机自动生成派工单，处理意见在通风页登记后回写派工清单，
  通风页与设施检修页读的是同一份数据；既有条目按验收日期归位，未验收的按登记时间推定。
- **材料导入判重口径**：批次按「批次号」判重——同一批次号重复导入只留最早那一版，
  不会多出一行；批内行按「机组编号」判重——新批次再报同一机组，整行业务字段以最新
  那版覆盖，不把两版并在一起。登记新机组同样按机组编号判重。
- **报表与明细对得上**：统计卡片、状态图例都与当前明细清单用同一批数据计算，
  导出清单的列与页面列同一份字段定义。
